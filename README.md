# Orbis

Orbis is a macOS desktop companion with reading, PDF viewing and retelling practice.

## Run locally

Prerequisites: Node.js 24, pnpm 10 and macOS.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Verify

```sh
pnpm verify
pnpm verify:rendered
```

The first command checks TypeScript and runs the application and reading-kernel
tests. The second builds the application and exercises its rendered interface.

## Build a macOS package

```sh
pnpm build
npx electron-builder --mac --publish never
```

Without an Apple Developer ID certificate this produces an unsigned development
package. macOS may require approval before opening it. Do not describe that
package as signed, notarized or as having a verified automatic-install path.

## GitHub releases

Push a `v*` tag whose version matches `package.json`. `.github/workflows/release.yml`
runs verification, builds Apple Silicon and Intel DMG/ZIP packages, validates
the published assets, and creates a GitHub release.

Apple signing and notarization run only when all five Apple repository secrets
are configured. Otherwise the workflow explicitly publishes a development build.

## Project layout

- `src/main`: Electron main process, local data, voice and reading integration.
- `src/preload`: permission-limited renderer API.
- `src/renderer`: companion, settings, history and reading windows.
- `src/kernel`: reading and PDF workspace used by the application.
- `src/shared`: shared contracts and formats.
- `resources`: application and tray assets.
- `scripts`: build, asset and verification tooling.
- `docs`: Orbis implementation notes.

External packages in `node_modules` and generated `vendor/pdfjs` assets are
runtime dependencies, regenerated by pnpm rather than separate projects in this
repository.
